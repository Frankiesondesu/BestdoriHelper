# 三端功能对照表

**维护约定**：任何一端加功能或修 bug，都要先看这张表，把另两端一起对齐（项目铁律 7）。

> **手机版 = 网页版**：同一份 `docs/`，只是套了 Capacitor 壳。
> 所以改网页版即改手机版，实际只需对照 **桌面 vs 网页/手机** 两方。

---

## 功能对照

| 功能 | 桌面（PySide6） | 网页 / 手机 | 状态 |
| --- | --- | --- | --- |
| 导入截图 | 选择图片… / **选择文件夹…** | 拖入 / 点选（支持整个文件夹） | ✅ 一致 |
| 文件列表管理 | **移除选中** / 清空列表 | 只有「清空」 | ⚠️ 差异 |
| 识别 | 开始识别 ▶ | 开始识别 | ✅ 一致 |
| 清空识别结果 | 清空识别结果 | 清空 | ✅ 一致 |
| **服务器选择** | 国服 / 日服 / 国际服 / 台服 / 韩服 | **固定国服** | ❌ 缺 |
| **界面语言** | 简体中文 / 其他 | 无 | ❌ 缺 |
| 切分参数 | 切分模式 / 行 / 列 / 内缩 | 同左（折叠区） | ✅ 一致 |
| **最低置信度** | 有（低于分数不进清单）| 无 | ❌ 缺 |
| **属性边框提示** | ☑ 开关 | 无 | ❌ 缺（影响切分准确率）|

| 看每格卡面详情 | 右侧核对面板（双图+属性+网址） | 点缩略图 → 点图 → 详情弹层 | ✅ 一致 |

| **打开 Bestdori 卡册页面** | 有按钮 | 无 | ❌ 缺（加个链接即可）|

| 记住登录 | `session.json` | localStorage + 原生 CookieManager | ✅ 一致 |
| **卡池更新 / 建指纹库** | 「同步」页 | 无，用预生成的 `docs/data/` | 见下② |
| 打开清单文件位置 | ✅ | 无（浏览器环境无意义） | 见下③ |

### 呈现方式差异（同类功能，不同形态 —— 属合理差异）

| | 桌面 | 网页 / 手机 | 为什么不同 |
| --- | --- | --- | --- |
| 结果页布局 | **三栏**：原图｜结果表｜核对面板 | **两栏** + 弹层 | 桌面屏幕大，三栏信息密度高；网页要兼容手机窄屏 |
| 运行日志 | 底部**常驻**（可收起）| **右下角抽屉** | 桌面空间充裕 |
| 参数面板 | 底部**常驻**一栏 | **折叠**（点展开）| 网页首屏要短 |

## 待补齐的功能缺口（截至 2026-09-19）

按影响面排序，均为**桌面有、网页/手机缺**：

| 优先级 | 缺口 | 影响 |
| --- | --- | --- |
| 高 | **服务器选择** | 网页版固定国服 —— 玩日服/国际服的认不出卡 |
| 高 | **最低置信度阈值** | 现在无法过滤「低分也进清单」|
| 高 | **属性边框提示开关** | 直接影响切分与识别准确率 |
| 中 | **允许「待确认」条目入清单** | 影响清单内容 |
| 中 | **只导入已确认条目**（同步页）| 影响写入 Bestdori 的内容 |
| 中 | **选择文件夹 / 移除选中** | 批量操作的便利性 |
| 低 | **OCR 文字辅助开关** | 可选功能，默认关 |
| 低 | **界面语言** | 目前只有中文，影响小 |
| 低 | **打开 Bestdori 卡册页面** | 加个外链即可 |

> 注：`服务器选择` 代价特殊 —— 每个服要单独生成一份约 45 MB 的卡池数据
> （缩略图 + 指纹库），仓库与网页体积会成倍增长。**只玩国服就不必做。**

---

### ① 网页版同步走「导出档案 → 官网 Import」

浏览器的同源策略挡死了直连：实测 Bestdori 的响应**没有任何 CORS 头**，
OPTIONS 预检直接 404。App 走原生 HTTP 没这个限制，所以能一键同步。

网页版的做法：清单页「导出 Bestdori 档案（可粘贴导入）」→ 复制 →
到 `bestdori.com/profile/manager` → Import → 粘贴。**凭据不经过任何第三方。**

### ② 网页版的卡池数据是构建时生成的

`docs/data/`（`cards.json` / `fingerprints.bin` / `thumbs/*.webp`，约 45 MB）
由脚本生成后再 push。**游戏出新卡时**要本机跑一遍：

```bash
bdh sync                    # 拉最新卡池
bdh index                   # 重建指纹库
python scripts/export_site_data.py   # 导出网页版用的数据
git add docs/data && git commit && git push
```

### ③ 文件系统相关操作只在桌面端

「打开清单文件位置」「打开 Bestdori 卡册页」这类依赖本地环境（或需要
不受限地开新窗口），浏览器里没有意义或做不到，属于设计上的差异。

## 加功能时的检查清单

1. **先想清三端各自怎么呈现**：桌面是按钮 / 面板，网页是按钮 / 弹层
2. **改完逐端验证**：

   | 端 | 验证手段 |
   | --- | --- |
   | 桌面 | `pytest`（320+ 例）+ `python scripts/gui_check.py` |
   | 网页 / 手机 | `python scripts/site_check.py` + 针对新功能的 Playwright 断言 |
   | 线上 | `python scripts/pages_live_check.py`（**改了 docs/ 之后必做**）|

3. **更新本表**（加了什么、哪端有哪端没有，写清楚）
