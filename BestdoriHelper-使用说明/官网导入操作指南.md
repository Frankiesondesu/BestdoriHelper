# 官网导入操作指南（逐步 + 按钮坐标）

> 这份文档里的坐标**全部是从真实页面上量出来的**（Playwright 读 DOM 的
> `getBoundingClientRect`），不是照着截图目测的。
> 测量环境：`https://bestdori.com/profile/manager`，视口 **1440 × 900**。
> 复现命令：`python scripts/annotate_bestdori_web.py`

---

## 先说结论：三步就完事

| 步骤 | 点哪里 | 坐标 (x, y) | 大小 |
|---|---|---|---|
| ① 登录 | 页面**中部** Cloud Storage 段里的 `Log In` | (531, 295) | 68×21 |
| ② 进导入页 | 左栏 `PROFILE` 组里的 `Import` | (49, 484) | 171×36 |
| ③ 粘贴 | 主区 `Profile Data` 文本框 | (495, 441) | 640×120 |
| ④ 确认 | 文本框正下方的 `Import` 按钮 | (495, 573) | 94×36 |

⚠️ **最容易踩的坑：登录入口不在右上角。**
官网右上角只有两个无文字的图标和一个 `Back`。真正的 `Log In` / `Sign Up`
藏在页面中部 "Cloud Storage" 那一段说明文字里
（原文：*To use cloud storage, you need to **Log In** 🔗 or **Sign Up** 🔗 first*）。

## 逐步操作

### 第 0 步：打开页面

浏览器进 **`https://bestdori.com/profile/manager`**。

> 第一次访问会弹一个 "Welcome to Bestdori!" 偏好设置框。
> **关掉就行**，不影响后面的操作。
> （它里面也有个 `Close` 链接；点掉之后页面才是上面坐标表描述的样子。）

### 第 1 步：登录（坐标 ①）

- **在哪：** 页面中部，`Cloud Storage` 标题下面那行说明文字里。
- **长什么样：** 一行小字 —— *To use cloud storage, you need to **Log In** 🔗 or
  **Sign Up** 🔗 first*。`Log In` 和 `Sign Up` 是带链接图标的蓝色文字。
- **点哪个：** 有账号点 `Log In`（x 531 附近），没账号点 `Sign Up`（x 623 附近）。
- **为什么必须登录：** 不登录也能看到导入框、也能粘贴，但**存不进云端**。

> 别去右上角找登录 —— 那里没有。

### 第 2 步：进到导入区（坐标 ②）

两种走法，效果一样：

- **走法 A（推荐）：** 左侧栏找到 `PROFILE`（第 7 个分组标题）→ 点它下面的
  缩进子项 `Import`。子项在左栏中下部，`Cloud Storage` 的下一行。
- **走法 B：** 直接往下滚。当前页 `Manager` 本身就包含 Import 区块，
  滚到 `Import` 这个 24px 大标题（页面 y ≈ 350）即可。

### 第 3 步：粘贴档案数据（坐标 ③）

- 在 `Import` 标题下方，找到 **`Profile Data`** 文本框 ——
  一个宽 640、高 120 的白色输入框，里面灰字提示 `Enter profile data`。
- 把 BestdoriHelper 导出的那段文本**整段粘进去**
  （网页版：清单页点「导出 Bestdori 档案」→ 弹层点「复制」）。
- 粘完不用做别的，文本框右下角有拖拽手柄可以拉大，方便检查。

### 第 4 步：点 Import 确认（坐标 ④）

- 按钮在**文本框左下角正下方**（不是右边，是下一行的左对齐位置）。
- 按钮样式：浅灰底、带边框、左边一个「导入」小图标 + 文字 `Import`。
- **别和侧栏那个 `Import` 搞混** —— 侧栏那个是导航菜单，这个才是执行导入。
- 点下去，导入完成。

## 两个容易搞混的东西

### 1. 侧栏的 `Import` vs 主区的 `Import` 按钮

| | 侧栏 `Import` | 主区 `Import` 按钮 |
|---|---|---|
| 位置 | 左栏 (49, 484) | 主区 (495, 573) |
| 外观 | 一条菜单项，171×36 | 一个按钮，94×36，带图标 |
| 作用 | 跳到导入区块 | **真正执行导入** |
| 何时点 | 第 2 步 | 第 4 步 |

### 2. `Import` 区块 vs `Premade Profile` 区块

两个区块紧挨着，`Import` 在上（y ≈ 350 起），`Premade Profile` 在下
（y ≈ 641 起）。

`Premade Profile` 是「按服务器 / 卡牌数 / 技能等级 / 大师等级**凭空造一份**档案」
的工具，**不是**用来导入你自己数据的。它有 Server（5 个圆形服务器图标）、
Cards up to 下拉框、Skill Level（1–5 按钮）、Master Rank（0–4 按钮）。
**不用碰它。**

---

## 关于「满值」的说明

BestdoriHelper 导出档案时，等级 / 技能 / 剧情数这几项**填的是满值** ——
因为这些东西从一张卡面截图里判断不出来。

- **影响：** 官网的算分（乐队综合力之类）。
- **不影响：** 卡牌的归属 —— 也就是「你有哪些卡」这件事是准的。
- 想要精确分数，导入后在官网自己改一下这几项即可。
